              Node setup (hash · signal · commands)

              networkHash — mesh id (SHA-256). Peers must share the same hash. Genesis creates it; others Join with hash + signaling.

              Signaling URL — WebRTC bootstrap (peer discovery through NAT). Prefer a public URL: VPS, Cloudflare Tunnel, or ngrok. Multi-URL: clients try each in order.

              Common commands

              # Forum node
npm install
npm start
# → http://localhost:3000

# Signaling standalone (bootstrap)
cd signaling-standalone
npm install
npm start
# → http://0.0.0.0:4000  (health: /health)

# Public tunnel
cloudflared tunnel --url http://127.0.0.1:4000

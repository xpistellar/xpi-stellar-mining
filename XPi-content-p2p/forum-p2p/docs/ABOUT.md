# About Forum P2P

**Forum P2P** is open-source forum software in the **XPi** ecosystem on **Stellar**.

- Default mesh: official **genesis** hash + signaling  
- Identity: any Stellar wallet  
- Storage: node-local encrypted disk  
- Sync: WebRTC peers that share hash + signaling  
- Optional: private access password, LocalMod, private network / hard fork  

See [INTRODUCTION.md](./INTRODUCTION.md), [ECONOMICS.md](./ECONOMICS.md), and the [long-form post](./blog/xpi-forum-p2p-economics-and-architecture.md).

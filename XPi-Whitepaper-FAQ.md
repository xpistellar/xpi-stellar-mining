# XPi: A Scarce Digital Asset on Stellar for Long-Term Ownership

**XPi** is a fixed-supply token issued on the Stellar network.  

On-chain data from **Stellar Expert** shows:

- **Issuer**: `GDOFJEZ3FUWAC2EVHPRMJPSWPOD3KJF7FTXFZIERFFPB2VMTRQLZFUEF`
- **Domain**: xgoldmining.com
- **Issuer status**: Locked
- **Authorization flags**: None
- **First transaction**: 18 July 2025

The asset currently has hundreds of trustlines, tens of thousands of payments and trades, and active order books on Stellar’s built-in DEX.

### Design Principles

The project is built around three core principles:

1. **Fixed scarcity**
2. **Slow and transparent distribution**
3. **Accessibility** through ordinary Stellar wallets

Less than **15%** of the supply is retained by the operating group. This portion is intended to remain largely uncirculated, serving a protective role similar to early Bitcoin addresses that have stayed dormant.

The remaining supply is released at a fixed rate of **21 XPi per day** through a Soroban smart contract. At this pace, the community portion requires roughly **7,000 years** to be fully distributed.

### How Users Obtain XPi

Users obtain XPi by **staking XLM** in the contract. Rewards scale roughly linearly with the amount staked.

**Example**:  
31.4 XLM yields approximately **0.0000003 XPi per day**.

- Users retain full control of their **private keys**
- No KYC is required for staking
- All logic is verifiable on-chain

Because Stellar nodes can run on ordinary hardware and the network already includes a native DEX, path payments, memos, and low fees, XPi inherits a mature infrastructure rather than building one from scratch.

> **The goal** is not short-term trading on centralized exchanges.  
> It is to offer an asset that is scarce enough to function as a long-term store of value and simple enough for ordinary people to own directly.

# 50 Frequently Asked Questions

### 1. What is money?
Money is anything widely accepted as a medium of exchange. XPi aims to serve as a scarce digital asset that people can own directly on Stellar instead of relying solely on trust in a central issuer.

### 2. What are the three main functions of money?
Medium of exchange, unit of account, and store of value. XPi focuses on the store-of-value function through its fixed 63 million supply and very slow daily release of only 21 XPi.

### 3. How does fiat currency differ from gold?
Fiat can be printed at will; gold is naturally scarce. XPi mimics gold’s scarcity while being far easier to divide and transfer because it runs on Stellar.

### 4. Why do people need a store of value?
To protect purchasing power from inflation. XPi’s extremely slow issuance schedule (roughly 7,000 years for the community portion) is designed to limit dilution.

### 5. Why is Bitcoin called digital gold?
Because its supply is capped at 21 million and cannot be arbitrarily increased. XPi also has a fixed supply (63 million) but is much easier for ordinary people to obtain by simply staking XLM.

### 6. Why is it hard for average people to mine Bitcoin?
It requires specialized hardware and large amounts of electricity. With XPi, staking as little as 31.4 XLM is enough to start earning—no mining rigs needed.

### 7. Why are private keys important?
Whoever controls the private key truly owns the coins. XPi users hold their own keys in regular Stellar wallets; balances are not stored on a project server.

### 8. Was early Pi Network real crypto?
Many argue it was not, because users did not control private keys and balances lived on centralized systems for a long time. XPi avoids this by being on-chain on Stellar from the start.

### 9. How does scarcity create value?
Assets that are difficult to inflate tend to better preserve value over time. XPi releases only 21 tokens per day, so new supply grows extremely slowly.

### 10. Can something be both scarce and easy to own?
Yes. XPi keeps a hard supply cap and ultra-slow distribution while letting anyone participate by staking a modest amount of XLM.

### 11. What is XPi’s total supply?
Exactly 63,000,000 XPi, verifiable on Stellar Expert. The issuer account is locked.

### 12. How much does the operating group hold?
Under 15%. This portion is mainly kept as a protective reserve to reduce the chance of large holders accumulating heavily and creating sharp price swings, similar to early dormant Bitcoin addresses.

## 1. Node.js CLI Tool (Ubuntu)

A simple command-line tool to stake, unstake, claim rewards, and check your balance.

### Requirements

- Ubuntu 20.04 or newer
- Internet connection

### Step 1: Install Node.js

```bash
sudo apt update
sudo apt install -y curl
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
node -v
npm -v
```

### Step 2: Create project folder

```bash
mkdir ~/xpi-staking
cd ~/xpi-staking
```

Download or create the file `stake-claim.js` and paste the Node.js staking script into it.

### Step 3: Install dependencies

```bash
npm init -y
npm install @stellar/stellar-sdk
```

### Step 4: Run the tool

```bash
node stake-claim.js
```

You will be asked for your Stellar secret key (starts with `S...`).

**Menu:**

1. Stake XLM (minimum 31.4)
2. Unstake XLM (press Enter or type `0` to unstake all)
3. Claim XPi rewards
4. View current stake
5. View pending rewards
6. Exit

### Important

- Never share your secret key.
- Make sure your account has enough XLM for the stake + network fees.
- You can unstake at any time.

## 3. Build the Android App from Source (Ubuntu + Android Studio)

### Requirements

- Ubuntu 22.04 or newer
- At least 8 GB RAM
- ~15 GB free disk space

### Step 1: Install Java

```bash
sudo apt update
sudo apt install -y openjdk-17-jdk git unzip wget
java -version
```

### Step 2: Install Android Studio

1. Download from: https://developer.android.com/studio
2. Extract and run:

```bash
tar -xzf android-studio-*.tar.gz
sudo mv android-studio /opt/
/opt/android-studio/bin/studio.sh
```

3. Complete the setup wizard and install:
   - Android SDK
   - Android SDK Platform (API 34+)
   - Android SDK Build-Tools

### Step 3: Get the source

```bash
unzip app.zip -d xpi-android
cd xpi-android
```

### Step 4: Open in Android Studio

1. Open Android Studio → **Open** → select the `xpi-android` folder.
2. Wait for Gradle sync to finish.

### Step 5: Build APK

1. **Build → Build Bundle(s) / APK(s) → Build APK(s)**
2. Find the APK at:
   - `app/build/outputs/apk/debug/app-debug.apk`

### Step 6: Install

Transfer the APK to your phone and install it, or connect the phone via USB and click **Run** in Android Studio.
